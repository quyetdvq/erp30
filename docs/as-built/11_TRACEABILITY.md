## 3. Điều kiện đóng traceability khi nâng cấp

Với mỗi CR, thêm hoặc cập nhật dòng TR: `source class/function`, `public/internal API`, `affected schema/seed`, `UI route/component`, `unit/integration/e2e test`, `evidence`. Việc source path không tồn tại hoặc OpenAPI route lệch phải làm fail static QA. Nếu backend feature có logic mà không có UI, ghi **“API-only”**; không mặc định frontend còn thiếu là bug khi tính năng có chủ ý chỉ cung cấp API. Với test hiện có mà chưa chạy, ghi rõ `EXISTS / NOT-RUN`.
