Framework bootstrap (`app/Config` defaults, `public/index.php`, `spark`, `.htaccess`) is adapted from the existing CodeIgniter 4 application starter distributed with DinkERP v1.2.4. See `LICENSE.codeigniter-starter`. Business services, routing rules, security integration, HTTP boundary, and Identity/Access implementation in v2 are new files. Third-party frameworks/libraries must be installed using Composer; no vendor files are bundled.
